## SWITCH Function Implementation

Used the `SWITCH()` function to classify products by sales volume:

- **High** sales (>600)
- **Medium** sales (300–600)
- **Low** sales (<300)

Example:

```excel
=SWITCH(TRUE,C2>600,"High",C2>=300,"Medium","Low")
```

This allowed products to be automatically categorised for reporting and analysis.
